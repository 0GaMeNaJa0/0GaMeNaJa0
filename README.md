## 🛰️ Developer, in one signal

I'm **Game**, a full-stack developer from Thailand who enjoys tracing an idea all the way to a dependable system.

I don't see an application as just a UI and an API. I see the complete path:

```text
Request → DNS → Network → Service → Data → Cache → Queue → AI → Infrastructure
```

My current obsession is building practical LLM and RAG applications with the unglamorous-but-essential parts done well: retrieval quality, context, evaluation, reliability, and system design.

> **North star:** build with enough depth that the product still works when the demo is over.
